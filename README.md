Project Name : FitLog — Workout Library 🏋️

Short Description : FitLog is a modern workout library and planning app that helps users explore workouts, view detailed exercise information, add workouts to today’s plan, save workouts for later, and track their daily workout progress.

Technologies Used : Next.js,React,TypeScript,Tailwind CSS,Next.js App Router,React Toastify,REST API,LocalStorage.


5 key features of the project : 1.Workout Library — Browse workouts with images, muscle groups, equipment, duration, calories, and ratings.
2.Today's Plan — Add up to 5 workouts to today's workout plan and manage them easily.
3.Save for Later — Save workouts for later and access them from the Saved section.
4.Workout Details — View complete workout information, including equipment, difficulty, sets, reps, calories, rating, and instructions.
5.Toast Notifications & Progress Tracking — Get instant notifications for workout actions and mark planned workouts as completed.
